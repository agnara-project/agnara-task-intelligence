# Security Policy

## Supported Versions

Since this is a historical reference application, only the current main branch and the specific documented versions of Agnara are supported.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please DO NOT report it by creating a public GitHub issue.

Please report it via GitHub Private Vulnerability Reporting if enabled for this repository. 
If it concerns the Agnara framework itself, please refer to the core Agnara repository's security policy.

## Scope
- This repository must NEVER contain secrets, credentials, tokens, or real environment variables.
- It is intended as a demonstration and reference. It should be run in isolated or local environments.
